# Creative Web Development

Ten projekt jest prostym projektem edukacyjnym. Służy do nauki tworzenia efektów, animacji i layoutów w aplikacji webowej, a także do eksperymentowania z technologiami front-end.

## Informacja o zasobach

W tym punkcie, na tym etapie nauki, korzystam z elementów wizualnych i inspiracji zaczerpniętych z gry Firewatch. Nie jestem autorem tych zasobów. Zostały one skopiowane ze strony:

https://www.firewatchgame.com/

To jest jedynie tymczasowy materiał edukacyjny i referencyjny, używany wyłącznie do nauki i ćwiczeń.

## Cel projektu

- nauka pracy z Angular
- eksperymenty z CSS i animacjami
- budowanie prostych, kreatywnych efektów wizualnych
- rozwijanie umiejętności w zakresie front-endu

## Uruchomienie

```bash
npm install
npm start
```

Po uruchomieniu projekt można otworzyć w przeglądarce pod adresem lokalnym używanym przez Angular.

## Uwaga

To nie jest oficjalny projekt ani materiał stworzony przez twórców Firewatch. Jest to wyłącznie projekt edukacyjny, wykonany w celach naukowych i ćwiczeniowych.
