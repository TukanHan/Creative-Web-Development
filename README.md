# Creative Web Development

Ten projekt jest prostym projektem edukacyjnym. Służy do nauki tworzenia efektów, animacji i layoutów w aplikacji webowej, a także do eksperymentowania z technologiami front-end.

## Cel projektu

- nauka pracy z Angular
- eksperymenty z CSS i animacjami
- budowanie prostych, kreatywnych efektów wizualnych
- rozwijanie umiejętności w zakresie front-endu

## Inspiracje i sposób pracy

W projekcie znajdują się koncepty zaczerpnięte z prac i eksperymentów innych twórców, które odtwarzam w celach edukacyjnych. Nie ograniczam się jednak do wiernego kopiowania — wprowadzam własne zmiany, rozwijam poznane rozwiązania i nadaję im indywidualny charakter.

W pracy nad projektem korzystam również ze wsparcia AI: przy generowaniu kodu, wymyślaniu pomysłów oraz wyborze i stosowaniu technologii. Nie określiłbym tego jednak jako „vibe coding” — AI jest dla mnie narzędziem wspierającym proces, a kierunek projektu, decyzje i końcowy rezultat pozostają po mojej stronie.

## Uruchomienie

```bash
npm install
npm start
```

Po uruchomieniu projekt można otworzyć w przeglądarce pod adresem lokalnym używanym przez Angular.
